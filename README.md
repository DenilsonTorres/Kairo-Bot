# Kairo Bot

Landing page criada para praticar conceitos de front-end, organização de layout e estilização moderna utilizando HTML e CSS.

## 🚀 Sobre o projeto

Kairo Bot é uma interface fictícia inspirada em bots de automação para Discord, com foco em um visual futurista e minimalista.

O projeto foi desenvolvido com o objetivo de revisar e praticar:

- Estruturação com HTML
- Estilização com CSS
- Flexbox
- Organização de sections
- Hover effects
- Responsividade
- Componentização visual
- Design moderno

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Landing page moderna
- Cards de funcionalidades
- Estatísticas do sistema
- Visual futurista
- Layout organizado e responsivo
